# HydroDAQ

An engineering-focused data acquisition and analysis system for collecting, processing, storing, and analyzing sensor measurements from hydraulic systems.

## Objectives

- Acquire sensor measurements using embedded systems.
- Process and validate incoming sensor data.
- Store structured measurements in a relational database.
- Analyze time-series data and identify system behavior.
- Apply signal processing and condition-monitoring techniques.

## System Architecture

1. **Data Acquisition:** Embedded C software for sensor interfacing, sampling, and data transmission.
2. **Data Processing:** Python for ingestion, validation, cleaning, and transformation.
3. **Data Storage:** SQL database for structured measurement storage and querying.
4. **Data Analysis:** Python for statistical analysis, visualization, signal processing, and condition monitoring.

## Development

The project initially uses recorded measurements from the UCI Condition Monitoring of Hydraulic Systems dataset to develop and validate its data-processing and analysis pipeline.

Future development will introduce hardware-based data acquisition.
